│                                                                             │

│   │  │                     │      │   │                  │              │  │

│   │  │                     │      │                     │              │  │
│   │  └─────────────────────┘      └─────────────────────┘              │  │
│   │                                                                     │  │
│   └─────────────────────────────────────────────────────────────────────┘  │
│                                                                             │
│   点击后的处理序列:                                                          │
│   ────────────────                                                        │
│                                                                             │
│   ┌────────────────────────────────────────────────────────────────────┐   │
│   │                                                                    │   │
│   │  1. 用户点击卡片                                                   │   │
│   │       │                                                            │   │
│   │       ▼                                                            │   │

│   │       │                                                            │   │

│   │       ▼                                                            │   │

│   │       ▼                                                            │   │

│   │       │                                                            │   │
│   │       ▼                                                            │   │
│   │  6. 模拟键盘事件 Cmd+V                                             │   │
│   │     ┌──────────────────────────────────────────────────────┐      │   │
│   │     │ let source = CGEventSource(stateID: .hidSystemState)│      │   │
│   │     │                                                      │      │   │
│   │     │ // Key Down: Cmd+V                                   │      │   │
│   │     │ let keyDown = CGEvent(                               │      │   │
│   │     │     keyboardEventSource: source,                     │      │   │
│   │     │     virtualKey: 0x09,  // V key                     │      │   │
│   │     │     keyDown: true                                   │      │   │
│   │     │ )                                                    │      │   │
│   │     │ keyDown?.flags = .maskCommand                       │      │   │

│   │     │                                                      │      │   │

│   │     │ )                                                    │      │   │
│   │     │ keyUp?.flags = .maskCommand                         │      │   │
│   │     │ keyUp?.post(tap: .cghidEventTap)                    │      │   │

│                                                                             │

│  │     │                                                               │   │
│  │     ▼                                                               │   │

│  │     │                                                               │   │
│  │     ▼                                                               │   │

│  │     │                                                               │   │
│  │     ▼                                                               │   │
│  │  Time 55ms    检查 Accessibility 权限                               │   │
│  │     │                                                               │   │
│  │     ├── 无权限 → 弹出引导窗口                                       │   │
│  │     │                                                               │   │
│  │     ▼                                                               │   │

│  │     │                                                               │   │
│  │     ▼                                                               │   │
│  │  Time 70ms    完成 ✓                                                │   │
│  │                                                                     │   │
│  └─────────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│  关键代码逻辑:                                                              │
│  ────────────                                                              │

│  }                                                                         │
│  ```                                                                       │

## 六、分类检测逻辑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                  ContentAnalyzer 检测流程                                    │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  输入: NSPasteboardItem                                                    │
│                                                                             │
│  ┌──────────────────────────────────────────┐                              │
│  │ Step 1: 检查二进制数据                     │                              │
│  │ - 是否有 .image 数据? → 图片               │                              │
│  │ - 是否有 .fileURL? → 文件                  │                              │
│  └──────────────────┬───────────────────────┘                              │
│                     │ 非二进制                                               │
│                     ▼                                                       │
│  ┌──────────────────────────────────────────┐                              │
│  │ Step 2: 检查富文本格式                     │                              │
│  │ - 有 .rtf/.rtfd? → 富文本                 │                              │
│  │ - 有 .html? → HTML                        │                              │
│  └──────────────────┬───────────────────────┘                              │
│                     │ 纯文本                                                │
│                     ▼                                                       │
│  ┌──────────────────────────────────────────┐                              │
│  │ Step 3: 文本内容分析                       │                              │
│  │                                          │                              │
│  │ if startsWith("http://") ||              │                              │
│  │    startsWith("https://") ||             │                              │
│  │    startsWith("ftp://")                  │                              │
│  │    → 链接                                │                              │
│  │                                          │                              │
│  │ if startsWith("data:image/")             │                              │
│  │    → 图片 Base64                         │                              │
│  │                                          │                              │
│  │ if matches(imageUrlPattern)              │                              │
│  │    (.png/.jpg/.gif/.svg 结尾)            │                              │
│  │    → 图片 URL                            │                              │
│  │                                          │                              │
│  │ if contains(codePatterns)                │                              │
│  │    (```、func、class、import、            │                              │
│  │     def、SELECT、<div> 等)              │                              │
│  │    → 代码块                              │                              │
│  │                                          │                              │
│  │ if contains(markdownPatterns)            │                              │
│  │    (# 、```、**、- 、[]() 等)           │                              │
│  │    → Markdown                            │                              │
│  │                                          │                              │
│  │ else → 纯文本                            │                              │
│  └──────────────────────────────────────────┘                              │
│                                                                             │
│  输出: ClipCategory 枚举值                                                  │
│                                                                             │
