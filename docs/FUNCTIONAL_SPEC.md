# ClipNote - 功能规格文档

## 1. 核心功能

### 1.1 剪贴板监听

**功能描述**: 自动监听系统剪贴板变化，捕获用户复制的内容。

**输入**: 用户复制的内容（文本、图片、文件等）

**输出**: 自动分类并存储到本地数据库

**实现细节**:
- 轮询间隔: 0.5 秒
- 检测方式: `NSPasteboard.changeCount` 变化
- 支持格式: 文本、RTF、HTML、图片、文件URL

**验收标准**:
- [x] 0.5 秒内检测到剪贴板变化
- [x] 正确识别 10 种内容类型
- [x] 跳过密码管理器内容
- [x] 不影响系统性能

### 1.2 智能分类

**功能描述**: 自动分析剪贴板内容并分类。

**分类列表**:

| 分类 | 识别规则 | 示例 |
|------|----------|------|
| 纯文本 | 默认分类 | "Hello World" |
| 链接 | http/https/ftp 开头 | "https://github.com" |
| 代码块 | 包含代码特征 | "func hello()" |
| Markdown | 包含 MD 语法 | "# 标题" |
| HTML | 包含 HTML 标签 | "<div>" |
| 富文本 | RTF/RTFD 格式 | 从 Notes 复制 |
| 图片 URL | 图片后缀 | "https://.../img.png" |
| Base64 图片 | data:image/ 开头 | "data:image/png;..." |
| 图片 | TIFF/PNG 数据 | 从 Finder 复制 |
| 文件 | 文件 URL | 从 Finder 复制 |

**验收标准**:
- [x] 准确率 > 95%
- [x] 处理时间 < 10ms
- [x] 支持多语言代码

### 1.3 点击即粘贴

**功能描述**: 点击卡片后自动将内容粘贴到当前焦点窗口。

**流程**:
1. 用户点击卡片
2. 内容写入系统剪贴板
3. 面板隐藏 (0.05s 延迟)
4. 模拟 Cmd+V 键盘事件
5. 内容粘贴到目标窗口

**前置条件**:
- 辅助功能权限已授权
- 目标窗口有输入焦点

**验收标准**:
- [x] 点击后 0.1 秒内完成粘贴
- [x] 支持所有文本输入框
- [x] 支持图片粘贴（支持的应用）
- [x] 权限未授权时弹出引导

### 1.4 水平滚动面板

**功能描述**: 水平滚动展示剪贴板历史，类似 Spotlight 的浮动面板。

**布局**:
- 宽度: 900px
- 高度: 400px
- 卡片尺寸: 200×280px
- 卡片间距: 12px

**交互**:
- 水平滚动浏览
- 鼠标悬停放大效果
- 点击选中并粘贴
- 键盘 ← → 导航

**验收标准**:
- [x] 流畅的滚动体验
- [x] 悬停动画效果
- [x] 响应式布局

### 1.5 全局快捷键

**功能描述**: 通过快捷键快速唤出/隐藏面板。

**默认快捷键**:
- 唤出/隐藏: `⌥⌘V`

**自定义**:
- 支持用户自定义快捷键
- 自动检测快捷键冲突

**验收标准**:
- [x] 全局可用
- [x] 不与其他应用冲突
- [x] 支持自定义

### 1.6 全文搜索

**功能描述**: 快速搜索剪贴板历史。

**搜索范围**:
- 内容文本
- 来源应用
- 分类标签

**搜索方式**:
- FTS5 全文索引
- 实时搜索 (300ms 防抖)
- 模糊匹配

**验收标准**:
- [x] 搜索响应 < 50ms
- [x] 支持中文搜索
- [x] 支持模糊匹配

### 1.7 分类筛选

**功能描述**: 按分类筛选剪贴板历史。

**分类标签**:
- 全部
- 纯文本
- 链接
- 代码
- 图片
- 富文本

**验收标准**:
- [x] 一键切换分类
- [x] 显示分类计数
- [x] 与搜索联动

### 1.8 内容预览

**功能描述**: 根据内容类型显示不同的预览方式。

**预览类型**:

| 类型 | 预览方式 |
|------|----------|
| 纯文本 | 文本内容 |
| 链接 | URL + 网站标题 |
| 代码 | 语法高亮 + 语言标签 |
| Markdown | 源码/预览切换 |
| HTML | 源码/WebView 预览 |
| 图片 | 缩略图预览 |
| Base64 | 解码后预览 |
| 文件 | 文件名 + 图标 |

**验收标准**:
- [x] 正确显示各类型预览
- [x] 代码语法高亮
- [x] Markdown 渲染正确

### 1.9 菜单栏入口

**功能描述**: 在菜单栏显示应用图标，提供快速访问。

**功能**:
- 显示最近 5 条复制记录
- 快速打开面板
- 打开设置
- 退出应用

**验收标准**:
- [x] 菜单栏图标显示
- [x] 最近记录更新
- [x] 点击操作响应

### 1.10 设置页面

**功能描述**: 应用设置和配置。

**设置项**:
- 通用: 开机自启动、轮询间隔
- 快捷键: 自定义全局快捷键
- 数据: 存储限制、清空数据、导出
- 关于: 版本信息、权限状态

**验收标准**:

## 3. 用户场景

### 场景 1: 程序员复制代码

```
1. 在 VSCode 选中代码
2. 按 ⌘C 复制
3. 按 ⌥⌘V 唤出面板
4. 看到代码卡片（带语法高亮）
5. 点击卡片
6. 代码粘贴到目标编辑器
```

### 场景 2: 复制链接分享

```
1. 在浏览器复制链接
2. 按 ⌥⌘V 唤出面板
3. 看到链接卡片（带网站标题）
4. 点击卡片
5. 链接粘贴到聊天窗口
```

### 场景 3: 复制图片

```
1. 在 Finder 复制图片
2. 按 ⌥⌘V 唤出面板
3. 看到图片卡片（缩略图）
4. 点击卡片
5. 图片粘贴到邮件/消息
```

### 场景 4: 搜索历史记录

```
1. 按 ⌥⌘V 唤出面板
2. 在搜索栏输入关键词
3. 实时过滤显示匹配结果
4. 点击卡片粘贴
```

### 场景 5: 按分类浏览

```
1. 按 ⌥⌘V 唤出面板
2. 点击"代码"分类标签
3. 只显示代码类内容
4. 水平滚动浏览
5. 点击卡片粘贴
```
